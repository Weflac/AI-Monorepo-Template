# specs — 规格文档（SDD）

每个 feature 一个目录，编号递增：

```
specs/
├── templates/            # spec / plan / tasks 模板
├── 001-xxx/
│   ├── spec.md           # WHAT & WHY
│   ├── plan.md           # HOW
│   └── tasks.md          # 任务拆解与进度
└── ...
```

流程说明见 [docs/sdd-workflow.md](../docs/sdd-workflow.md)。
